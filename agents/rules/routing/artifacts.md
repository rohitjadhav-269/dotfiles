# Brand and artifact skill routing

Load this reference for brand identity, UI concept images, static visual art, or theming an existing artifact.

| Request | Primary owner |
| --- | --- |
| Generate a brand identity board, logo system, identity deck, or brand-kit image | `brandkit` |
| Explicitly invoke imagegen-frontend-web for website section comps | `imagegen-frontend-web` — named only |
| Explicitly invoke imagegen-frontend-mobile for mobile screen/flow concepts | `imagegen-frontend-mobile` — named only |
| Create original static poster or artwork as PNG or PDF | `canvas-design` |
| Apply a preset or custom theme to a slide deck, document, report, or similar artifact | `theme-factory` |

Do not use these artifact skills as application design-system or product-interface implementation authorities.

The two imagegen frontend skills produce images through the existing imagegen
backend. Generic design or website requests retain their current owners. Honor
the requested image count; clarify an unspecified batch size before rendering.
Additional generations require scope for those renders. Preserve existing brand
and design authorities, and hand implementation to the normal interface owner.
